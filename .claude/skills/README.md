# Agent skills

The workflow skills (`check-docs`, `finish-change`, `retro`, `review-change`, `start-task`)
are links to `.agents/skills/`, installed from
[agentic-workflow](https://github.com/Fridcot/agentic-workflow); see
`docs/operations/agent-workflow.md`.

The `aspire*` and `dotnet-inspect` skills in this directory were installed by `aspire agent init`
from [microsoft/aspire-skills](https://github.com/microsoft/aspire-skills) (MIT License,
Copyright (c) Microsoft Corporation). Re-run `aspire agent init` to update them.
